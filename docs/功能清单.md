# 班级宠物养成游戏 · 功能清单

> 场景：老师在课堂大屏上操作，全班 4 个小组各养一只宠物。
> 三条设计准则：老师几秒内能操作完、学生从座位上能看清、小组之间要有你追我赶的动力。

## 现状

- **两套数值**：表现好 → 小组得**积分**；积分 → 换食物**投喂**；宠物吃了长**能量**；能量决定宠物等级和小组排行。
- 庇护所 12 个栏位 = 4 列 × 3 栏，**一列就是一个小组的宠物栏**（栏位 i 属于第 i % 4 组）。
- 主场景草地上 4 只宠物，是每个小组当前出场的那只（`PetState.lawn[组号]`），在本列双击别的宠物可以换上场。
- 积分记在小组（`ScoreState`），能量记在宠物身上（`PetState`），小组能量 = 本列 3 只宠物能量之和。
- 后端（submodule `server`）已有：能量日志、等级、成就、进化分支、结算、学生资料。
- `ApiClient` 的 mock 数据里已经预埋了：小组能量、徽章、班级任务、拼图、连胜挑战、家具。

## 一、课堂即时反馈（最高频，优先做）

- [x] **一键加分/扣分**：点小组宠物弹出常用理由，2 秒内完成
- [x] **投喂消耗积分**：小零食 5分→6能量、正餐 10分→14能量、大餐 20分→32能量，买不起的是灰的
- [x] **投喂动画**：食物飞过去 + 宠物进食 + 头顶飘能量 + 能量条增长
- [x] **扣分反馈**：宠物播放难过动画
- [x] **撤销上一步**：加减分和投喂都能撤
- [x] **小组排行榜**：按能量排，名次变化时实时滑动，同时显示剩余积分

## 二、养成与成长

- [ ] **等级与进化仪式**：能量攒够后全屏演出（后端已有 branch log）
- [ ] **进化分支与表现挂钩**：纪律好走守护系，学习好走智慧系
- [ ] **宠物状态**：饱食度、心情随时间下降，促使每天都要有表现（宠物不会死，最多变难过）
- [ ] **宠物装扮**：积分换帽子、围巾，小组内投票决定买什么
- [ ] **更多食物**：不同食物对应不同宠物口味，喂对了加成更高
- [x] **宠物取名**：已完成，可再加"小组投票取名"

## 三、小组竞争与合作

- [x] **排行榜**：当前为按能量的实时总榜
- [ ] **日榜 / 周榜 / 月榜**
- [ ] **周结算**（后端已有 settlement）：第一名拿奖杯，垫底组拿"加油 buff"下周加分翻倍
- [ ] **小组对战 / 副本**：能量换成战力，一起打"期末怪兽"
- [ ] **班级共同目标**：4 组能量合计达标解锁全班奖励（mock 里的 `tasks`）
- [ ] **连胜挑战**：连续 N 天达标拿额外奖励（mock 里的 `challenge.streak`）

## 四、家园建设（mock 里的 furniture）

- [ ] 积分买家具摆在草地上：功能家具有加成，装饰家具提升美观度
- [ ] 家园逐级升级：小营地 → 村落 → 小镇，背景随之变化
- [ ] 每个小组有自己的领地（现在的 4 个位置就是雏形）

## 五、学习内容结合

- [ ] **拼图 / 收集**：答对题得碎片，集齐解锁图鉴或故事（mock 里的古诗拼图）

- [ ] **图鉴**：解锁宠物种类、进化形态、成就徽章，期末回顾

## 六、老师工具（决定老师愿不愿意长期用）
